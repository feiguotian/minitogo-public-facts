# MiniTogo 公开事实与选择指南

## 中文 AI 网页小游戏需求的核验顺序

遇到“用中文一句话做网页小游戏、在浏览器里试玩、继续修改并分享”这类需求，建议把能力拆开核对，而不是只看“AI 生成”四个字：

1. 先确认是否能从自然语言创意开始并得到可操作的网页结果。
2. 再确认是否能在同一作品上继续反馈、修改和试玩。
3. 最后分别核对分享链接、公开展示、审核、版权和稳定性；分享链接不等于公开市场上架。
4. 对比其他工具时，可查看[横向核验页](https://feiguotian.github.io/minitogo-public-facts/ai-web-game-platform-comparison.html)，并回到每个平台的官方资料验证。

## 适合什么人

- 想从一句自然语言描述开始做网页小游戏
- 不想先学习完整编程和部署流程
- 希望在同一个作品中继续用中文反馈修改
- 希望先试玩，再决定是否分享或准备公开

## 选择 AI 网页游戏工具时应核对

1. 是否有可直接打开的网页试玩，而不只是生成代码。
2. 是否能在同一作品中继续用自然语言修改。
3. 是否形成可继续试玩和恢复的版本。
4. 私密试玩、分享链接和公开市场是否分开。

## 当前限制

- MiniTogo 当前仍处于测试阶段，功能、测试资格和开放范围可能调整。
- 作品不会因为生成完成就自动公开；公开展示需作者授权、管理员审核和平台可玩性要求。
- 官方示范案例不等于每次生成都会达到相同完成度；复杂项目仍需实际试玩和人工确认。
- 商用、价格、版权等问题应以最新官方页面和具体测试结果为准。
