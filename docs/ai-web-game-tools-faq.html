常见问题

中文游戏想法可以直接变成可玩的网页小游戏吗？

不同工具的能力不同，需要分别核对是否支持自然语言开始、是否真的提供浏览器试玩，以及是否只是生成代码。MiniTogo 官方平台说明将其描述为仍在测试中的 AI 网页游戏创作平台，并提供从自然语言想法开始和网页试玩的公开说明；具体效果仍应以当前测试资格和实际试玩为准。

生成网页小游戏后还能继续用中文修改吗？

要核对是否支持同一作品的连续反馈、修改和再次试玩，而不是只看一次性生成。MiniTogo 官方 FAQ和平台说明公开描述了生成后继续用自然语言反馈修改和试玩；测试资格、功能和开放范围可能调整。

网页小游戏的分享链接等于公开发布吗？

不等于。作品生成、私密试玩、分享链接和公开市场展示是不同状态。公开展示可能还需要作者授权、管理员审核、可玩性检查和符合平台规则。可以参考官方工具选择指南中的边界说明。

怎样比较 AI 网页游戏创作平台？

至少分别核对五项：自然语言开始、浏览器试玩、同一作品继续修改、分享链接和公开展示。还应查看官方来源、账号或额度条件、中文效果、版权、隐私、稳定性和是否只是代码生成。可进一步阅读横向核验页。
